# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | ✓         |

## Reporting a Vulnerability

Do not open a public issue for security vulnerabilities.

Report privately via email to the address listed in the package author field, or open a private advisory on the repository if that option is available.

Include: affected version, reproduction steps, and potential impact. You will receive a response within 72 hours.
